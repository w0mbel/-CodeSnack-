# CodeSnack 🚀

Willkommen bei **CodeSnack**! Dieses Repository dient als zentrale und automatisch aktualisierte Datenbank für IPTV-Portal-URLs (Stalker-Portale) und den dazugehörigen MAC-Adressen.

## 🌟 Features
*   **Automatisierte Erfassung:** Ein eigens entwickelter Python-Crawler durchsucht das Netz nach neuen Portalen und MACs.
*   **Modernes Web-Interface:** Die Daten werden auf einer eigens dafür erstellten GitHub Page im stylischen Dark-Mode-Design präsentiert (inspiriert von stbemu).
*   **Intelligente Suche:** Filtere live nach bestimmten Portal-URLs, um sofort alle dazugehörigen MAC-Adressen zu sehen.
*   **One-Click Copy:** Jede MAC-Adresse kann mit einem einzigen Klick in die Zwischenablage kopiert werden.
*   **Daten-Historie:** Neue Einträge werden ergänzt, ohne alte zu überschreiben.

## 🛠️ Technologien
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (gehostet via GitHub Pages)
*   **Backend/Scraper:** Python (Requests, BeautifulSoup, SQLite, GitHub API)
